# hotel-cancellation-revenue-analysis
Análisis completo de 119K reservas hoteleras en India. ETL, EDA, dashboard interactivo (Plotly) y modelo ML para predecir cancelaciones (AUC-ROC 93.27%).

## Proyecto de Data Science: Análisis de Cancelaciones y Revenue en Hoteles

Este repositorio contiene un análisis exhaustivo de 119,390 reservas hoteleras 
en India durante 2024. Incluye:

- **ETL completo** con limpieza de datos, manejo de nulos y feature engineering
- **Análisis Exploratorio** con visualizaciones estadísticas y detección de patrones
- **Dashboard interactivo** con 6 visualizaciones en Plotly
- **Modelo ML** (Random Forest) para predicción de cancelaciones con AUC-ROC 93.27%
- **Informe ejecutivo** con recomendaciones estratégicas

**Stack:** Python, Pandas, Scikit-learn, Plotly, Jupyter

**Resultados clave:** 
- Revenue total: €25.9M
- Tasa cancelación: 37%
- Feature más importante: lead_time
